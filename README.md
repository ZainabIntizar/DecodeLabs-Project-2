# DecodeLabs Project 2 — The Art of Fluidity

A responsive Front-End Development project by **Zainab Intizar**.

## Built with
- HTML5
- CSS3
- CSS Grid
- Flexbox
- Media Queries
- Fluid units and `clamp()`
- Small JavaScript navigation toggle

## Requirements covered
- Mobile-first responsive layout
- Responsive navigation
- Grid for macro layout
- Flexbox for component alignment
- Fluid sizing and spacing
- Accessible navigation labels and focus-friendly controls
- Desktop, tablet and mobile layouts

## Run locally
Open `index.html` in a browser, or use VS Code + Live Server.
